# hxyfront-62008 烟花燃放脚本编排台

面向烟花燃放编排师的燃放脚本编排工具：音乐时间点是唯一时间源，节目段落、点火批次都锚定在时间点上，时间点一改，绑定批次与后续火力自动重算。

## 功能

- **时间轴编排**：音乐时间点（唯一时间源）→ 节目段落 → 点火批次三层显示。点时间点标签或拖滑块改时间，所有绑定批次整体重排；人工偏移（±3s）和手动角度在重算后保留。
- **点位容量排队**：同一时点、同一点位并发批次超出通道容量时，按"先点火型号的占用时长"自动顺延，并在时间轴、明细表、点位图、冲突面板标出点位与型号；扩容后排队自动消失。
- **点位平面图**：SVG 场图标注点位容量、最大口径、发射角度连线、安全距离半径圈；点位纵深小于该点最大型号要求安全距离时红色报警并给出缺口米数。
- **点火批次明细**：按实际点火时间排序，展示期望时间 / 人工偏移 / 排队延迟 / 口径 / 角度（可人工覆盖，回填型号默认值即恢复跟随）/ 安全距离。
- **冲突时间提示**：容量排队（warn）、安全距离不足（danger）、同点跨型号窗口交叠（warn），点击可定位到对应视图。
- **整场节目预览**：按段落汇总火力 cue 单，与时间轴、点位图读同一份派生数据，三处始终是同一版方案（版本号 vN 同步显示）。
- **写盘失败保护**：提交失败的版本先进本地「待提交区」不丢失，可手动"立即补写"；页面刷新/重开时自动检测并按顺序继续补写。提供"模拟写盘故障"开关演示该流程；待提交版本可载入或丢弃。

## 数据与重算模型

- `src/types.ts`：型号、点位、音乐时间点、段落、批次及派生类型。
- `src/engine.ts`：时间解析/格式化、通道贪心排队（`computeQueue`）、点火序列（`computeRows`）、点位口径/角度/安全距离汇总（`computePositionStats`）、冲突检测（`computeConflicts`）。
- `src/storage.ts`：不稳定写盘模拟 + 待提交区（outbox）+ 恢复补写（localStorage 持久化）。
- `src/components/`：Timeline / PositionMap / FiringTable / ConflictPanel / ShowPreview / SaveBar。
